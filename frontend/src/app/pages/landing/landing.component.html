A recording of the real flow — question, retrieval, answer, evidence.

The problem isn't that AI is wrong.

It's that it's wrong confidently, in fluent prose, with no way to tell the difference from a glance.

Ask most document assistants a question and you get a paragraph. It sounds right. It might be right. But checking it means going back to the document and finding the passage yourself — which is the work you were trying to avoid.

So this tool refuses to answer without showing you the receipt.

Four steps, and you can audit every one.

  1. Your document is read and indexed

    PDFs and Word files are parsed page by page, keeping the position of every line. Scanned pages fall back to OCR automatically, so image-only documents still work.

  2. Your question finds the relevant passages

    Retrieval is deterministic vector search over the document's own text — no model deciding what it remembers. In Quality mode it runs several rounds, each one looking for what the previous answer still hadn't covered.

  3. The answer is written from those passages only

    Two scores come back with it, both computed from the text rather than self-reported by the model: how well retrieval matched, and how closely the answer tracks its sources.

  4. You click the citation and land on the page

    Every claim carries the page it came from. Click it and the exact passage is highlighted in the document, so verifying an answer takes a second rather than a search.

What this does that a chat window doesn't.

Your documents never leave this machine

The language model, the embeddings, the search index and the database all run locally in containers on your own hardware. Nothing is uploaded to a third-party API, which matters rather a lot if the document is a contract, a medical record, or unreleased work.

Claims checked against the open web

A claim from your document can be verified against outside sources, each one listed with its domain and whether it supports or contradicts the claim.

Read it as clean text, or as data

Every document is also available as structured Markdown, with headings and lists recovered and running page furniture stripped — or as JSON blocks, if you want to build on top of it.

Selection is a first-class action

Highlight a passage to explain or summarise it. Drag a box around a diagram, chart or screenshot and the same actions work there too — read by OCR where there's text, and described by a vision model where there isn't.
